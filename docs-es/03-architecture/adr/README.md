# Registros de decisiones de arquitectura

> Estado: borrador (draft).

Esta carpeta contiene un ADR por cada decisión de arquitectura que los propios documentos del repositorio de escritorio registran como decisión. Cada ADR cita dónde está registrada la decisión. Las elecciones que solo aparecen en el código, o que se dejaron abiertas, se listan en [Sin decidir / no registrado](#sin-decidir--no-registrado) y no tienen ADR.

**Formato.** `NNNN-kebab-title.md` con Contexto, Decisión, Consecuencias y Estado. El estado dice `accepted (recorded in <source>)`, o `accepted, amended in part (...)` cuando un documento posterior cambió parte de la decisión.

**Citas.** Las rutas sin prefijo de repositorio están en `gentle-shell-desktop@5ab4a00`. Los IDs de otras páginas llevan calificador (`audit A8`, `gap G9`); M1–M6 sin calificador son los hitos del mantenedor, y los números T son tareas dentro de ellos.
